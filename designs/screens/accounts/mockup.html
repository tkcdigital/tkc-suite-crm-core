Design notes

Use the mockup controls at the top: change the relation type and the user role, and watch panels, fields and subpanels appear or disappear. This is how six OSC workspaces become one layout.

Mapping decisions

  • One layout for detail and edit (SuiteCRM Angular). Edit mode is shown for the General panel and the Links fields.
  • OSC ribbon: Save, Save and close, New, Appointment, Copy, Delete, Print map to header actions. Refresh and Spell check are browser functions (dropped). Editor links dropped. Bookmark becomes the favourite star.
  • Grid actions (Open, New, Add existing, Remove, Delete) map to the standard subpanel Create, Select and row menu. Subpanel Print and Copy have no equivalent (gap).
  • Dropped by owner decision: SLA, Projects. Dropped by proposal: Login, Password, Company image, the two RN CRM credential fields.
  • Address: street, postal code, city, country only. The OSC state menu is a US state list and is not shown. Standard fields without OSC use (website, industry, employees) are left out of the layout; open question 10.
  • Hourly rates and expected revenue are free text in OSC and shown as text. Labels follow the OSC label, not the OSC field name (question 6).
  • Not set in OSC booleans: Has RightNow and Projects on portal show the segmented Yes/No with no choice selected.

[custom] items for the architect

  • Role-based displayLogic. Cell displayLogic on type is standard. A condition on the user role needs a custom logic function or a flag field. Assessment S3: logic goes on cells, not panels.
  • Hide an empty tab or panel. When all cells hide, the tab and panel header must hide too. Not confirmed as standard; may need an Angular tweak.
  • Field-level ACL for Finance. Not verified in SuiteCRM 8.10. If missing, the fields are only hidden, not protected. Security officer must see this.
  • Relation type as a pill in list and header (enum display component).
  • External links built from tkc_replicon_name_c and tkc_sharepoint_name_c (field type with URL template).
  • Contracts subpanel with columns that depend on type (AOS_Contracts, contract_type). Layout with Support fields only for type Support.
  • Save and close button, and Print as PDF (AOS PDF template).
  • Three-state Yes/No for nullable flags (no value selected) as a segmented radio field.

Open questions

  • Which of the 6 types need a separate layout, or is the conditional layout enough (questions 9, 13)?
  • Is the report "Site Werkzaamheden" (Klant Algemeen) needed as a subpanel (question 4)?
  • Keep or drop CRM modules "State" (question 5)? Which URL is current for Replicon and SharePoint (question 12)?
  • Contracts: meaning of Kanalen, unit of Duur and Change drempel, status (question 17). Layout shows the core fields only.
  • Does Sales see Finance on all Klant records, or only own records? Role "Sales" = profile 73 in OSC.
