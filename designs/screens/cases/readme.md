# cases screen

## Oracle Service Cloud

The OSC counterpart of the suiteCRM cases entity is **Incident** 

A customer inquiry, complaint, problem, or service request.
Chronological **message threads** (customer messages, agent responses, internal notes, attachments); categorized by status (*Unresolved*, *Waiting*, *Solved*), priority, severity, product, and category.
Associated with a primary **Contact** and optionally an **Organization**; assigned to a queue or service agent.
Central work unit for customer service agents, automated routing, escalations, and resolution monitoring via SLAs.
