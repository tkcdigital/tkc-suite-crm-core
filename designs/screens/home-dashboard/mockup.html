Design notes

What legacy dashlets can do (restyle only, no Angular dashboard)

  • The Home module renders in the legacy layer (home: index/list/record = false). Dashlets, dashboard tabs, "Add dashlets" and drag-and-drop between columns stay as they are. We change colours, type, radius, spacing, table rows and icon buttons through the Dawn theme CSS (.dashletPanel, table.list.view, .moduleTitle).
  • Standard dashlets shown: My Cases, My Opportunities (pipeline), Upcoming Calls/Meetings/Tasks (activities), My Accounts, Activity Stream. The three header icons (refresh, edit, remove) are the legacy ones, restyled as ghost icon buttons.
  • Column layout: the legacy dashboard has 1 to 4 columns that the user chooses. The mockup uses a responsive grid as the target. On phones the dashlets must stack to one column; the legacy CSS needs a media-query override for that.
  • Status and priority are plain text in legacy list cells. The pill look needs the value wrapped in a span (see custom list).
