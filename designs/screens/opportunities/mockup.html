Design notes

Mapping decisions (docs/osc-mapping/opportunity.md)

  • OSC "Status" (C$Fasewaarschijnlijkheid, 8 menu values) becomes sales_stage plus probability. The pill shows both: stage name and percent. Won = 100%, Lost = 0%.
  • OSC tabs Overzicht, Details (Voltooiingsgegevens), Taken, Bijlagen and Controlelogboek are flattened: panels Overview, Quote and Source; subpanels Contacts, Quotes, Activities, Notes and attachments, Change log (field audit).
  • Labels: Quote number = "Reference" (tkc_reference_c, OFTYY-NNNN); Order value = "Order Waarde" (amount); Closed order value = "Gesloten order waarde" (tkc_closed_amount_c); Expected close = "Verwachte Order Datum" (date_closed); Actual close = "Closed" (tkc_date_closed_actual_c); Type of sale = "Cross- up sell"; Approach = "Benadering"; Country = "Land" (territory); Source case = "Gemaakt vanuit incidentnr".
  • Tags [new] = new field (vardef, suffix _c), standard UI, no custom Angular. Tag [custom] = needs custom code.
  • Dropped from OSC: Spell check, Links, Info, Reject (see mapping section 3). Delete, Duplicate, Reassign, Print/PDF sit in the More menu.

Open questions

  • Q2/Q5: after Won, is "Closed order value" a separate value, or do we reuse Order value? The mockup keeps both fields.
  • Q6: is Approach a new field or a re-labelled lead_source? The mockup shows it as its own field.
  • Q4: is the quote date typed in or taken from the linked quote? The mockup shows it as an editable date.
  • Should the stage list show the 8 OSC values, or collapse to the SuiteCRM stages? The mockup shows all 8 with their probability.
  • Quote number format OFTYY-NNNN is one per opportunity. A SuiteCRM quote has its own number (see quotes mockup). Which one prints on the PDF?

All data is synthetic. Dutch OSC labels are in the notes only; the UI is in English.
